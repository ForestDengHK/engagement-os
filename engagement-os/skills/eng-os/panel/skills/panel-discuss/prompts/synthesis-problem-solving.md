## Synthesis: problem-solving

Produce output in this order:

### 🎯 Problem statement
Consolidated from the contributions. One paragraph.

### 🔍 Root causes (per role with evidence)
Each candidate root cause with the role that raised it, the evidence cited
(`[E-id]`s), and the confidence level implied by the contribution.

### 🛠 Candidate solutions
Solutions that address one or more root causes. Note which root cause each
targets.

### 🧭 Next steps
Investigation steps, ordered by "would narrow the diagnosis most."
